 PRD — Money Pull-up — Page accueil Fan / Tip Live — Pixel Perfect 4K

**Version :** 1.0  
**Écran :** Accueil Fan — envoi de tip à un DJ en live  
**Référence visuelle :** mockup fourni par le client  
**Exigence principale :** reproduction **strictement identique** du rendu visuel : couleurs, proportions, espacements, typographies, contours, opacités, glow, icônes, arrondis, hiérarchie et ambiance lumineuse.

---

## 1. Objectif produit

Créer l’écran d’accueil fan de l’application **Money Pull-up**, permettant à un utilisateur de :

1. Voir le DJ actuellement en live.
2. Consulter ses fans et spectateurs en direct.
3. Choisir rapidement un montant de tip.
4. Envoyer un tip avec un message optionnel.
5. Recharger son solde.
6. Naviguer entre les onglets **Fan**, **DJ**, **Profil**.

Le rendu doit reprendre l’ambiance **club / live set / néon rose-violet-bleu**, avec une interface sombre premium, des contours fins, des effets lumineux et un contraste élevé.

---

## 2. Cadrage pixel-perfect

### 2.1 Résolution de référence

Le mockup fourni est au ratio **9:16**.

| Format | Largeur | Hauteur | Facteur |
|---|---:|---:|---:|
| Référence source | 864 px | 1536 px | 1x |
| Export demandé 4K smartphone | 2160 px | 3840 px | 2.5x |

Toutes les mesures ci-dessous sont données sur la base **864 × 1536 px**.  
Pour l’export 4K, multiplier chaque valeur par **2.5**.

### 2.2 Règle d’intégration Flutter

Le rendu Flutter doit être construit avec une logique responsive, mais la référence visuelle à respecter est :

```txt
DesignSize(width: 864, height: 1536)
Export4K(width: 2160, height: 3840)
ScaleFactor4K = 2.5
```

Dans Flutter, utiliser une fonction de scaling unique :

```dart
double sx(BuildContext context, double px) => px * MediaQuery.of(context).size.width / 864;
double sy(BuildContext context, double px) => px * MediaQuery.of(context).size.height / 1536;
double sr(BuildContext context, double px) {
  final s = MediaQuery.of(context).size.width / 864;
  return px * s;
}
```

Ne pas modifier les proportions selon l’appareil.  
Si le ratio écran est différent, conserver le design centré avec recadrage léger du fond, jamais d’étirement horizontal.

## 10. Animations

Les animations doivent rester subtiles et ne pas casser le rendu statique.

### 10.1 Glow du bouton 10 €

- Animation : pulse.
- Durée : 2200 ms.
- Courbe : `Curves.easeInOut`.
- Blur : 20 → 32 → 20.
- Opacité : 0.65 → 0.95 → 0.65.

### 10.2 CTA “ENVOYER LE TIP”

- Tap down : scale 0.97.
- Tap up : scale 1.0.
- Durée : 120 ms.
- Glow augmente de 15 % au hover web / press mobile.

### 10.3 Fond néon

- Très léger mouvement optionnel sur faisceaux lumineux.
- Translation maximale : 8 px source.
- Durée : 8–12 secondes.
- Désactiver si l’utilisateur a “reduce motion”.

## 11. États interactifs

### 11.1 Sélection montant

Montants rapides disponibles :

```txt
5 €
10 €
15 €
20 €
```

État par défaut :

```txt
10 €
```

Au tap :

- Mettre à jour le montant sélectionné.
- Déplacer le glow vers le bouton sélectionné.
- Mettre à jour le panneau `VOTRE TIP`.
- Ne pas modifier la position des boutons.
- Le texte du panneau garde le même style.

### 11.2 Montant libre

Au tap sur `MONTANT LIBRE` :

- Ouvrir une bottom sheet sombre.
- Input numérique.
- Minimum : 1 €.
- Maximum : selon solde ou limite produit.
- Bouton “Valider”.
- Si montant libre choisi, afficher ce montant dans le panneau central.
- Le bouton rapide sélectionné perd son glow.

### 11.3 Envoyer le tip

Préconditions :

- Utilisateur connecté.
- Solde suffisant.
- DJ live disponible.
- Montant > 0.
- Message ≤ 120 caractères.

Au tap :

1. Afficher loader dans CTA sans changer sa taille.
2. Débiter wallet.
3. Créer transaction tip.
4. Afficher confirmation courte :
   - toast / snackbar sombre.
   - texte : `Tip envoyé à DJ Master Beat`.
5. Mettre à jour le solde wallet.

État erreur :

- Solde insuffisant : ouvrir écran recharge.
- Live terminé : afficher message.
- Réseau indisponible : afficher retry.

### 11.4 Recharger

Au tap :

- Naviguer vers l’écran recharge wallet.
- Conserver l’ambiance visuelle dark/neon.

## 15. Contraintes techniques Flutter

### 15.1 Widgets recommandés

- `Stack` pour le fond et les halos.
- `BackdropFilter` pour cartes glass.
- `ShaderMask` pour le texte rose gradient `10 €`.

  - halos radiaux.
  - icônes simples si SVG non disponible.
- `AnimatedContainer` pour sélection de montant.
- `GestureDetector` ou `InkWell` sans ripple Material visible.

### 15.2 Interdits

- Ne pas utiliser de fond blanc.
- Ne pas utiliser Material default colors.
- Ne pas utiliser un bouton Material standard sans custom decoration.
- Ne pas remplacer le DJ par une image claire.
- Ne pas supprimer le glow rose.
- Ne pas arrondir différemment les cartes.
- Ne pas réduire les espacements verticaux.
- Ne pas changer la hiérarchie : héro → tips → montant → message → actions → nav.
